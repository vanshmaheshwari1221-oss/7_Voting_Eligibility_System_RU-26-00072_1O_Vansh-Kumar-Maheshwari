## Problem Statement

Write a program that takes a person's name, age and citizenship, checks whether the person is eligible to vote, gives the reason when not eligible, and allows more voters to be checked in a loop.

*Language: Python 3
*Concepts:Conditions, Functions, Exceptions

*Eligibility rule: A person is eligible if age is 18 or more **and** the person is an Indian citizen (y/n). A valid age is a whole number from 0 to 120.

**Bare Minimum Requirements:**
1. Write the solution in Python 3 (one .py file) and run it from the console.
2. Take the name, age and citizenship of the person as input.
3. Use if-elif-else conditions inside a function such as `check_eligibility()`.
4. Handle invalid age input using try-except and ask again until a valid age is entered.
5. Show the reason when the person is not eligible and the final count of voters checked.

**How to run:**
```
python voting_eligibility.py
```
